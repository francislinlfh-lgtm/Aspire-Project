## 1. Autopsy of Drift Lab v3.1

### 1.1 What it actually is

The prototype is an LLM-as-brain system wearing a thin computational costume:

| Component | Claimed nature | Actual nature |
|---|---|---|
| "Theory modules" (`MODULES`) | psychological mechanisms | prose strings interpolated into prompts |
| Trust / warmth | relationship state | scalars, but **deltas are self-reported by the LLM** (`trust_delta` in the JSON reply) — the agent grades its own homework |
| Memory | episodic memory | an array of ≤10 unstructured strings, FIFO-truncated |
| Opinions (`OP`) | interpersonal beliefs | one-line prose rewritten wholesale by the LLM |
| Gossip routing | social reasoning | three hand-coded `if` statements keyed on character id |
| Behavioral triggers | cognition | regexes over surface text (`/quit|violin|orchestra/i`) |
| Attachment / dissonance | explicit mechanisms | **genuinely computational** — two small linear formulas feeding thresholds |

The two engine formulas — `attachmentActivation()` and `dissonancePressure()` — are the
seed of the real idea: a number computed in code crossed a threshold and *caused* Emma to
walk over. The player could inspect why. Everything else delegated cognition to the
prompt.

### 1.2 Why this ceiling is hard

1. **No falsifiability.** When the LLM decides trust moved by +0.1, there is no equation
   to be wrong. Nothing can be validated, ablated, or compared.
2. **No compositionality.** Prose modules cannot interact except inside the LLM's
   attention. Dissonance cannot modulate memory encoding; attachment cannot bias
   interpretation. Real constructs interpenetrate.
3. **No experimental control.** You cannot clamp a variable, run a counterfactual, or
   sweep a parameter across 500 seeded runs of a prompt vibe.
4. **No transfer.** Three characters = three hand-written personality essays. A fourth
   character costs a fourth essay. Parameterized agents cost a row in a table.

### 1.3 What survives — as requirements, not code

The prototype earns its keep as a *specification of target phenomena*:

- **The lens** → grows into the full cognitive debugger (§6).
- **Earshot / front-stage vs backstage** → becomes the perception model (M1) and
  dramaturgical display rules (M4).
- **The day cadence** → becomes the consolidation boundary (M5).
- **Emma's unprompted approach, Jake's flattery-immunity, Maya's public doubling-down** →
  become acceptance tests that must **emerge** from general mechanisms instead of being
  authored (Appendix B). The prototype is not the foundation; it is the test oracle.

## 2. Architectural commitments

Every design decision below traces to one of these five commitments.

**C1 — The cognition–language firewall.** All cognition happens in typed state and
explicit update rules. LLMs appear in exactly two stateless roles: a *parser* (text →
distribution over structured social acts) and a *renderer* (utterance plan → text), and
both are audited by round-trip checks (M13). The LLM is a transducer, never a mind.

**C2 — Glass box.** Every state variable is inspectable; every state change carries
provenance (which rule, which inputs). Any utterance can be exploded into its full causal
chain: event → construal → appraisal → emotion → memory → motive → plan → words.

**C3 — Theories as cartridges.** A module implements a *construct interface*
(e.g., "dissonance reduction") and any number of competing theories can implement the same
interface. Swapping cartridges — Festinger's dissonance vs. Bem's self-perception — and
comparing behavioral signatures is a first-class operation. The engine is a
theory-comparison instrument, not a theory.

**C4 — Determinism and replay.** `step(state, events, seed) → state'` is pure. LLM
boundary calls are recorded and replayable. Same seed + same inputs = same run, forever.
Without this there is no science, only anecdotes.

**C5 — Emergence over authorship.** Nothing character-specific may appear in engine code.
Characters are parameter vectors + initial state + a voice profile for the renderer.
If a behavior needs a per-character `if`, the mechanism is wrong.

## 3. The representational substrate

Four typed currencies flow through every module. Choosing them is the deepest design
decision in the project.

### 3.1 Events (the social event calculus)

Everything that happens is an event:

```ts
Event {
  id, t                       // time
  actor: EntityRef
  act: ActType                // speech act, physical act, expressive display, or absence
  target?: EntityRef
  content?: Proposition[]     // what was asserted/asked/promised
  manner: EPA                 // how it was done (affective coloring, see 3.3)
  setting: SettingRef         // carries its own EPA and norm context
  audience: EntityRef[]       // computed from spatial earshot
}
```

Crucially, no agent ever receives an Event directly. Each agent receives a **Construal**
(M1) — its own noisy, schema-filtered private copy. Misunderstanding is representable
because *the same event exists in k+1 versions*: one ground truth, k construals.

### 3.2 Propositions and graded beliefs

Content is symbolic and typed: `quit(maya, violin)`, `evaluates(jake, maya, −)`,
`promised(player, emma, attend(showcase))`. Agents never hold propositions raw; they hold
**Beliefs**:

```ts
Belief {
  p: Proposition
  credence: LogOdds           // graded, not boolean
  sources: SourceTag[]        // perceived | told-by(X, t) | inferred | reconstructed
  affect: EPA                 // how this belief feels to hold
  lastAccess: t[]             // feeds memory activation (M5)
}
```

### 3.3 EPA space (the affective currency)

Following **Affect Control Theory** (Heise 1979, 2007; Smith-Lovin), every identity,
behavior, emotion, and setting carries a 3-vector of **E**valuation (good↔bad),
**P**otency (powerful↔weak), **A**ctivity (lively↔quiet). ACT is the only mathematical
sociology framework with published, cross-culturally replicated empirical dictionaries
(thousands of concepts rated in EPA space) and regression equations for how events move
impressions. It gives us, for free:

- a common metric for identities, acts, and feelings,
- empirically fitted event dynamics (impression-formation equations),
- a scalar **deflection** that behaves like social-emotional "stress,"
- an action-selection principle (do what keeps meanings intact).

### 3.4 Appraisal space

Emotion generation uses a component vector (M2) following Scherer's Component Process
Model: relevance (novelty, intrinsic pleasantness, goal relevance), implication (agency,
intent, goal congruence, urgency), coping potential (control, power), and normative
significance (self-standards, social norms). Discrete emotions are *regions* in this
space, not primitives.

## 4. The cognitive stack

Thirteen modules. Each follows the same scaffold. Update rules are given in compact
ASCII math; all Greek letters are per-agent parameters (the personality layer, §4.14).

            │                      WORLD                         │
            │            events · space · time · things          │
            └───────────────┬────────────────────▲───────────────┘
                            │ events             │ acts
            ┌───────────────▼────────────────────┴───────────────┐
            │ M1 Perception & Construal                          │

### M1 · Perception & Construal

**Theory.** Constructivist perception; New Look psychology (Bruner); motivated
construal; mood-congruent interpretation (Bower 1981); Easterbrook (1959) arousal
narrowing.

**Construct.** *You don't respond to what happened; you respond to what you think
happened.*

**State.** Per agent: attention budget `att ∈ [0,1]`; construal log.

**Dynamics.** For each event within perceptual range, produce a Construal:

- **Detail gating:** probability of registering attribute k:
  `p_k = σ(base_k + att − dist_penalty − peripheral_k · arousal)`
  (high arousal narrows to central attributes — weapon-focus analog).
- **Ambiguity resolution:** ambiguous attributes (manner, intent) are filled by
  sampling from the perceiver's schema of the actor (M5) and current mood:
  `intent_hat = argmax_i P(i | schema(actor)) · exp(κ_mood · sim(i, mood))`.
- Whispered/private events out of earshot register only as
  `occurred(privateExchange(A,B))` — which is itself socially potent content
  (exclusion is perceivable even when content is not; this is what Emma reacts to).

**Predictions.** Hostile-attribution bias emerges for agents with negative schemas of the
actor; identical utterances produce divergent downstream cascades in different witnesses.

**Validation.** Feed one scripted scene to agents differing only in prior schema; measure
construal divergence; compare qualitatively with hostile attribution literature (Dodge).

**Nearest kin.** Appraisal architectures (EMA) fold construal into appraisal; keeping it
separate is what makes *misunderstanding* a measurable object (M12).

---

### M2 · Appraisal Engine

**Theory.** Scherer's Component Process Model; OCC (Ortony, Clore & Collins 1988);
EMA (Gratch & Marsella 2004); Lazarus.

**Construct.** Emotion elicitation: events matter only relative to goals, standards, and
coping capacity.

**State.** Stateless map, but parameterized: appraisal gain matrix `Γ` (trait layer).

**Dynamics.** For construal c: `a = Γ · φ(c, goals, norms, identity)` where φ computes:

| check | computed from |
|---|---|
| novelty | prediction error vs. schemas & scripts (M5) |
| goal congruence | Σ over active goals: impact × importance (M9) |
| agency & intent | construed actor + intent (M1) |
| coping potential | potency of self vs. actor (EPA), resources |
| norm compatibility | M11 norm store + M8 standards |
| identity relevance | deflection contribution (M10) & identity error (M8) |

Discrete emotion label = nearest prototype in appraisal space (anger = other-agency +
goal obstruction + high coping; fear = threat + low coping; shame = self-agency + standard
violation + audience; guilt = self-agency + harm to other; envy, pride, gratitude, …).
Labels matter only for display and recall (emotions are stored by vector).

**Predictions.** Same insult → anger in high-potency agents, shame/fear in low-potency
agents (matches appraisal literature). Blocking a goal the agent doesn't hold produces
nothing — no scripted "insult keywords."

**Validation.** Vignette batteries from appraisal studies (Scherer's cross-cultural
questionnaire scenarios) fed as events; check emotion-label agreement rates.

**Nearest kin.** EMA/FAtiMA do this well; the difference is our appraisal reads from —
and writes to — nine sibling modules with shared currencies rather than a bespoke store.

### M3 · Core Affect & Emotion Dynamics

**Theory.** Russell's core affect (2003); dynamical affect models; emotional inertia
(Kuppens et al. 2010); reinforcement sensitivity (Gray's BIS/BAS).

**Construct.** Mood as a slow-moving 2D state (valence v, arousal r) that biases
everything; emotions as impulses on top.

**State.** `x = (v, r)`, baseline `x₀`, per-agent decay `Λ`, physiological load `L` (from M4).

**Dynamics.**
```
x(t+Δ) = x + Δ · [ −Λ ∘ (x − x₀) + B·a(t) ]      (a = appraisal impulses)
```
Trait mapping: neuroticism ↑ gain on negative appraisals and ↓ decay for negative
valence (slow recovery); extraversion ↑ x₀.v and reward gain. Mood feeds back into M1
(congruent construal), M5 (congruent recall), M9 (goal valuation).

**Predictions.** Emotional inertia (autocorrelation of v) increases with neuroticism —
matching the depression-risk literature. Bad events cluster into bad *days* without any
scripting, because mood biases construal which feeds appraisal.

**Validation.** Fit Λ, B to experience-sampling datasets' autocorrelation structure;
reproduce inertia effects.

**Nearest kin.** ALMA/WASABI-style mood layers; ours is distinguished by closed loops
into perception and memory rather than a display-only mood.

### M4 · Emotion Regulation & Display

**Theory.** Gross's process model (1998); Goffman's dramaturgy (1959); display rules
(Ekman); ego-depletion-style load (used as an engineering variable, not a metaphysical
claim).

**Construct.** Felt affect ≠ displayed affect; the gap is strategic, costly, and leaky.

**State.** Regulation policy weights per strategy; display vector `d`; load `L`.

**Dynamics.** Strategy set as *operators*, chosen to minimize expected
`(felt distress + display-rule violation cost + energy cost)` under a cognitive budget:

- *Situation selection* → injects avoidance goals into M9 (don't go near Maya's topic).
- *Attentional deployment* → lowers M1 attention to a stimulus class.
- *Reappraisal* → re-runs M2 with modified construal (costs budget; also changes what M5
  encodes — regulated memories are stored regulated).
- *Suppression* → `d = felt − s`; load `L += κ|s|`;
  leakage probability `p_leak = σ(L + r − control)`. Leaks emit low-intensity expressive
  events other agents can construe.

Display rules come from setting + audience (front stage: `audience ≠ ∅`) + identity
standards. Goffman's front/backstage is now *derived*: it is the audience-conditional
display-rule policy, not a character trait — any agent has it to some degree; Maya's
parameters make it extreme.

**Predictions.** Suppressors leak under high arousal + load; observers with good models
(M7) detect felt/displayed gaps and construe "she's performing" — duplicity detection
emerges.

**Validation.** Reproduce suppression-vs-reappraisal signatures from Gross's studies
(suppression: display drops, physiological load rises; reappraisal: both drop).

**Nearest kin.** Almost no interactive system models the felt/display split as leaky
control. Façade authored it; we derive it.

### M5 · Memory: episodic, semantic, reconstructive

**Theory.** Tulving's episodic/semantic distinction; ACT-R declarative memory
(Anderson); Ebbinghaus decay; Bartlett (1932) reconstruction; fuzzy-trace theory
(Brainerd & Reyna) verbatim vs. gist; complementary learning systems (McClelland et al.
1995); flashbulb memory (Brown & Kulik 1977 — confident, not accurate); source
monitoring (Johnson, Hashtroudi & Lindsay 1993).

**Construct.** Memory is not storage; it is *reconstruction from traces + schemas*, biased
by present state.

**State.**
- **Episodic store:** traces = construals with per-attribute encoding strengths.
- **Schema store:** person schemas (distributions over attributes/EPA per person),
  event scripts (typical event sequences per setting), self-schemas (feeds M8).

**Dynamics.**
- **Encoding:** trace strength `ρ = σ(β₀ + β₁|r| + β₂·goalRel + β₃·novelty)`;
  per-attribute strengths modulated by M1's arousal narrowing (central ↑, peripheral ↓).
- **Activation (ACT-R):** `A_i = ln Σ_j t_j^(−δ) + Σ_k W_k·S_ki + ε`
  (base-level decay + spreading activation from current cues + noise); retrieve if
  `A_i > θ`. Mood similarity contributes to cue strength → mood-congruent recall.
- **Reconstruction:** recalled attribute = trace value if its strength > θ_attr, else
  **sampled from the schema conditioned on current beliefs**. This single rule yields
  false memories, attitude-consistent memory drift, and Bartlett-style normalization —
  without any dedicated "false memory feature."
- **Consolidation (the day boundary):** episodic traces cluster; schemas update toward
  cluster prototypes (gist strengthens); verbatim attribute strengths decay faster than
  gist (fuzzy-trace). The end-of-day screen is now a cognitive event, not a UI beat.

**Predictions.**
1. After a relationship sours, an agent's *recollection of ambiguous past events drifts
   negative* — their testimony changes though the log did not.
2. Gossip chains distort toward schema-consistency (serial reproduction, §7).
3. High-arousal event memories are vivid about central details, confidently wrong about
   peripheral ones.

**Validation.** Run DRM-style and serial-reproduction protocols *inside the sim*; compare
distortion signatures with the human literature.

**Nearest kin.** Generative Agents' memory stream stores strings and retrieves by
recency×importance×relevance — retrieval-augmented prompting, not memory. ACT-R has the
math but no social content. The reconstructive layer in an interactive agent is, to our
knowledge, new.

### M6 · Epistemics: beliefs, sources, trust

**Theory.** Source monitoring; testimony & epistemic vigilance (Sperber et al.);
Bayesian trust/reputation (Jøsang's beta reputation); the sleeper effect (Hovland).

**Construct.** Knowing *that* is inseparable from remembering *how you came to know* —
and forgetting the "how" changes the "that."

**State.** Belief store (3.2); per-source reliability `R_s ~ Beta(α_s, β_s)` maintained
per domain (Jake can trust Emma about people and not about deadlines).

**Dynamics.**
- **Update on testimony:** `logodds(p) += E[R_s] · strength(assertion)` with novelty and
  plausibility gates (`plausibility = fit to schemas`; wildly implausible claims update
  the *source's reliability* downward instead of the belief upward).
- **Verification events** (observing p directly after being told p) update `Beta(α,β)`.
- **Source decay:** source tags decay independently of credence
  (`p_forget_source ∝ t^γ`). A distrusted source's claim, once its tag is lost, is just
  a belief → the **sleeper effect falls out of the mechanism for free.**

**Predictions.** Rumors gain credibility as they age and detach from disliked sources;
"everyone knows X" states can arise from a single forgotten origin.

**Validation.** Sleeper-effect protocol in-sim; rumor propagation curves vs.
agent-network structure compared to diffusion literature.

**Nearest kin.** Computational trust is mature in multi-agent systems; wiring it into
reconstructive memory and gossip content (not just numeric ratings of sellers) is the new
part.

### M7 · Theory of Mind & Reflected Appraisal

**Theory.** Recursive mentalizing with depth limits (Kinderman; Stiller & Dunbar 2007);
PsychSim's recursive agent models (Pynadath & Marsella 2005); the looking-glass self
(Cooley 1902; Mead 1934); inverse planning (Baker, Saxe & Tenenbaum).

**Construct.** Each agent carries *compressed simulations of other minds*, including —
critically — a model of what others think of *them*.

**State.** For each acquaintance j: `Model_i(j)` = estimated EPA sentiments toward
salient entities, estimated goals/needs, salient believed-beliefs, and reliability.
Depth-2 slot: `Model_i(j, i)` — "what j thinks of me" (the **reflected appraisal**,
which M8 consumes). Depth is capped at 2 with fidelity decay; deeper recursion is
represented only as uncertainty.

**Dynamics.**
- **Inverse appraisal (abduction over ACT):** observing j do behavior b to o, infer the
  sentiment ŝ that would make b deflection-minimal for j; blend:
  `Model_i(j).sent(o) += k · (ŝ − Model_i(j).sent(o))` (Kalman-style gain k set by
  observation ambiguity).
- **Reflected appraisal:** j's acts toward *me* update `Model_i(j,i)` the same way.
- **Perspective simulation:** before acting, an agent can run a cheap forward model —
  apply M2 with j's estimated parameters to the planned act — to predict j's reaction.
  Budgeted: simulation depth and frequency are personality/motivation dependent
  (low-empathy or hurried agents skip it — tactlessness is a *resource decision*).

**Predictions.** Second-order misunderstandings ("she thinks I'm angry at her") arise and
persist until falsified; agents with poor models systematically mis-predict reactions
and generate more conflict per interaction.

**Validation.** False-belief-style probes in-sim; compare conflict rates vs. simulation
budget in ablation.

**Nearest kin.** PsychSim is the closest ancestor (decision-theoretic recursion). We
differ by grounding inference in ACT's empirically fitted event equations and feeding a
dedicated reflected-appraisal channel into an identity control loop (M8).

### M8 · Identity & Self

**Theory.** Identity control theory (Burke 1991; Burke & Stets 2009); self-discrepancy
(Higgins 1987); self-verification (Swann); cognitive dissonance (Festinger 1957) and
self-consistency reformulation (Aronson); narrative identity (McAdams).

**Construct.** The self is a *set of standards under active defense*: agents work to make
the world reflect back who they believe they are.

**State.**
- Role identities with **standards**: `S_r ∈ EPA` + trait claims (e.g., Maya: "creator,"
  E+ P+ A+; residual "musician" standard, dormant but not deleted).
- **Commitment store:** publicly defended propositions with
  `commit(c) = f(publicity, irreversibility, effort sunk)`.
- Identity distress accumulator; narrative log (self-relevant episode chain).

**Dynamics.**
- **Verification loop (Burke, literally a negative-feedback controller):**
  `e_r = reflectedEPA_r − S_r` (reflected appraisals from M7 aggregated over recent
  interactions); distress `+= |e_r|²`; behavior selection (M9) gets a bias toward acts
  whose *predicted* reflected appraisal reduces |e|.
- **Partner selection:** preference for interaction partners whose feedback verifies
  standards — **including negative standards** (Swann's self-verification: an agent with
  a low-E self-view is uncomfortable around excessive praise). This is a strange,
  strongly falsifiable behavioral commitment most systems would never make.
- **Dissonance:** `D = Σ_(p,c) credence(p) · commit(c) · inconsist(p,c) · (1 + γ·audience)`.
  Reduction operators, chosen greedily by cost: belief change (cheapest for
  low-commitment items), trivialization, consonant-information seeking (injects an
  information goal into M9), source derogation (writes to M6 reliability!).
  Maya's violin arc is now an *instance*: high-commitment public choice + repeated
  disconfirming evidence (800 views) + audience multiplier.
- **Identity change:** if |e_r| stays high past a hysteresis window, `S_r` drifts toward
  the reflected appraisal (slow time constant). Identities bend only after they've
  failed to bend the world.

**Predictions.** Public challenges harden positions while private, high-trust challenges
open them (v3.1 scripted this; here it *emerges* from the audience multiplier). Chronic
non-verification predicts either exit from the relationship or self-concept change —
never indefinite steady state.

**Validation.** Dissonance-paradigm replications in-sim (induced-compliance analog:
force an agent to publicly defend a position under low vs. high justification; measure
belief drift). Cartridge comparison: Festinger vs. self-perception implementations of the
same interface — do their behavioral signatures diverge measurably? (That comparison is
itself a publishable result.)

**Nearest kin.** No game system has an identity-verification control loop. Affect
control theory's "identity maintenance" is our substrate, Burke supplies the controller,
Swann supplies the partner-choice policy.

### M9 · Motivation: needs, goals, valuation

**Theory.** Self-determination theory (Deci & Ryan 2000): autonomy, competence,
relatedness; Dörner's PSI / Bach's MicroPsi (homeostatic reservoirs); prospect theory
(Kahneman & Tversky 1979; loss aversion λ ≈ 2.25); attachment dynamics (Bowlby;
Mikulincer & Shaver's activation model).

**Construct.** Behavior is in service of *need regulation*, not point-maximization.

**State.** Need reservoirs `n_k ∈ [0,1]` for k ∈ {autonomy, competence, relatedness,
stimulation}; adaptation-level reference points; active goal set with importance.

**Dynamics.**
- `dn_k/dt = −δ_k + Σ satisfaction(events)` — appraised events refill/drain reservoirs
  (praise → competence; being managed → autonomy drain; exclusion → relatedness drain).
- **Goal generation:** candidate acts scored
  `U(act) = Σ_k w_k · v(Δn_k) · urgency(n_k)` where `v` is the prospect value function
  (`v(Δ) = Δ^α` for gains, `−λ(−Δ)^β` for losses, reference = adaptation level) and
  urgency is convex near depletion.
- **Prospect-theoretic relationship protection:** once a relationship is a *possession*
  (reference point moved up), honesty risks are coded as potential losses ×λ — agents
  protect valued bonds instead of deepening them. (Emma's scripted module, now emergent
  for anyone with a valued bond.)
- **Attachment as relatedness control:** per-relationship security `s_ij`; activation
  `A = σ(k₁·threat + k₂·separation − k₃·s_ij)`. Style parameters route high activation:
  *hyperactivation* (anxious: protest behavior, proximity seeking — Emma's walk-over) or
  *deactivation* (avoidant: suppress the goal, leak into load L).
- **Autonomy reactance:** requests construed as pressure (M1: "you HAVE to") multiply the
  autonomy-loss term → refusal even against material interest (Jake's SDT module,
  generalized; cf. Brehm's reactance).

**Predictions.** Deprivation → sensitization (long-excluded agents overreact to small
slights); satiation → indifference. Reactance scales with construed pressure, not actual
request size.

**Validation.** Reservoir trajectories vs. behavior frequency (operant-style curves);
reactance paradigm replication in-sim.

**Nearest kin.** The Sims runs needs-as-meters (hunger, fun) — physiological, not
psychosocial, and with linear valuation. PSI/MicroPsi is the serious ancestor; we add
prospect-theoretic valuation and per-relationship attachment control.

### M10 · Relationships & Social Physics (Affect Control Theory core)

**Theory.** Affect control theory (Heise; Smith-Lovin; MacKinnon); BayesAct (Hoey,
Schröder & Alhothali) as the probabilistic extension; Fiske's relational models (1992)
as relationship-type grammar.

**Construct.** A relationship is a pair of *sentiments* (stable EPA meanings each party
holds of the other, per role frame) plus running *transient impressions*.

**State.** Per dyad, per agent: fundamental sentiment `f_ij ∈ EPA` (slow), transient
impression `τ_ij ∈ EPA` (fast); relational frame ∈ {communal, authority, equality,
market} (Fiske) which selects norm packages (M11) and exchange bookkeeping (Jake's
"ledger" is the market frame's bookkeeping, not a personality quirk).

**Dynamics.**
- **Impression formation:** after event (A, b, O), transients update via ACT's published
  regression equations `τ' = M · [f_A, f_b, f_O]` (empirically fitted; dictionaries give
  starting sentiments for hundreds of behaviors — *the engine ships with human data
  inside it*).
- **Deflection:** `D = Σ w_i (f_i − τ_i)²` — the felt wrongness of the situation. D feeds
  appraisal (M2) as a stress/normative term.
- **Action selection contribution:** candidate behaviors are scored partly by expected
  deflection `E[D | b]` — agents act to confirm established meanings. This is why a
  low-warmth agent *resists* sudden intimacy: kindness from a "cold" identity is
  deflecting, and gets construed as suspicious (M1 closes the loop).
- **Sentiment drift:** fundamentals move slowly toward chronic transients
  (`df/dt = ε(τ̄ − f)`) — relationships re-form around sustained new behavior, with
  time constants making repair slower than damage (negativity asymmetry via ε± split).
- Trust and warmth, v3.1's two floats, are *readouts*: warmth ≈ f.E, standing ≈ f.P,
  trust = M6's reliability expectation. They are no longer stored; they are computed.

**Predictions.** Identity-inconsistent kindness arouses suspicion rather than gratitude
(testable and counterintuitive). Deflection spikes predict both emotion intensity and
subsequent repair work.

**Validation.** ACT is the best-validated piece of the whole stack — impression-formation
equations replicate across cultures. In-sim: correlate deflection with observer-rated
awkwardness of generated scenes.

**Nearest kin.** BayesAct is the direct mathematical ancestor for this module alone; no
one has run it as the physics under a memory/identity/language stack.

### M11 · Norms as Distributed Objects

**Theory.** Bicchieri's grammar of norms (2006): empirical + normative expectations,
conditional compliance; Cialdini's descriptive/injunctive distinction; pluralistic
ignorance (Prentice & Miller).

**Construct.** A norm is not a world rule; it is a *belief structure inside each agent*
about what others do and expect.

**State.** Per agent, per context: descriptive estimate `D̂ ~ Beta` over behavior
frequency; injunctive strength `I` (inferred from observed sanctions and explicit norm
talk); internalization `ι` (identity-linked).

**Dynamics.**
- Observation updates `D̂`; witnessing sanctions updates `I`.
- **Compliance:** violate if
  `gain > I·p_detect·E[sanction] + ι·I` (external + internalized costs).
- **Sanctioning** is itself an act chosen by M9/M10 (enforcer identities gain
  verification from sanctioning; low-potency agents free-ride).
- Norm talk (M12) transmits `I` claims through M6's testimony machinery — norms can be
  *lied about*.

**Predictions.** **Pluralistic ignorance is reachable:** since injunctive beliefs are
inferred from public behavior only, a population can stably enforce a norm that no member
privately endorses. Norm death happens through visible unpunished violation cascades.

**Validation.** Reproduce norm-emergence/decay curves from experimental economics
(public-goods with punishment); demonstrate pluralistic-ignorance equilibrium and its
perturbation (one public dissent event).

**Nearest kin.** Agent-based norm models exist in JASSS-style literature but with
one-bit agents; embedding them in agents with memory, identity, and language makes the
*mechanisms of norm transmission* (gossip, sanction, display) endogenous.

### M12 · Conversation: common ground, speech acts, misunderstanding

**Theory.** Clark's common ground and grounding acts (1996); speech act theory (Austin;
Searle); Grice (1975); politeness theory (Brown & Levinson 1987); rational speech acts
(Goodman & Frank) for the probabilistic reading.

**Construct.** Conversation is *coordinated belief revision under uncertainty about
coordination itself.*

**State.** Per dyad, per agent: a **common-ground ledger** `CG_i(j)` — the agent's own
estimate of what is mutually established, with groundedness levels. There is no shared
ledger; there are two estimates. Their divergence is the system's formal definition of
**misunderstanding**, and it is a number.

**Dynamics.**
- **Production:** an utterance plan is assembled, not written:
  - *illocution + content* from M9 goals (inform, request, repair, bond, probe…),
  - *manner EPA* from M10 deflection-minimization (how this speaker would say it),
  - *politeness strategy* from face calculus: weight `W = D(S,H) + P(H,S) + R_act`
    (social distance + hearer power + imposition) selects bald / positive politeness /
    negative politeness / off-record — off-record acts are *deliberately parseable two
    ways*, which the listener model handles natively,
  - *display coloring* from M4 (felt vs displayed),
  - Gricean constraints prune content (don't assert what CG already contains — unless
    re-assertion is the point, which is itself a detectable social move).
- **Comprehension:** parser (M13) returns k candidate parses with likelihoods; the
  listener's posterior multiplies in its priors — schemas of the speaker, mood
  congruence, reflected appraisal ("does she like me?") — and takes the MAP. A hostile
  listener hears the barb in a neutral remark *by Bayes, not by script*.
- Both sides update their `CG` estimates; **repair** (clarification questions,
  restatements) triggers when parse confidence < θ or when subsequent events are
  improbable under the adopted parse.
- **Gossip** is not a subsystem: it is an inform-act whose content is a belief about an
  absent third party, produced when M9 finds value in it (relatedness bonding, status,
  norm enforcement — the functions in Dunbar's and Foster's gossip literature) and M6/M5
  supply the (possibly already-distorted) content. Recipient choice falls out of
  goal-value per audience — v3.1's three hand-coded `if`s become a scoring rule.

**Predictions.** Misunderstanding rate scales with CG divergence and parse ambiguity;
politeness strategies shift measurably with power/distance manipulations; serial gossip
mutates toward the *teller's* schemas at each hop.

**Validation.** Referential-communication-style tasks in-sim (do dyads converge on
shorthand? — Clark & Wilkes-Gibbs); politeness-strategy distribution vs. W, compared with
corpus studies.

**Nearest kin.** Versu had social practices; Façade had beats; neither had per-agent CG
ledgers with measurable divergence. RSA gives the probabilistic core but has never been
embedded in agents with memory and identity.

### M13 · The Language Boundary (the firewall itself)

**Theory.** None — this is engineering discipline in service of C1. But it is the
architecture's most consequential module.

**Contract.**

```
Parser  P: text × sceneContext → Dist[SpeechActFrame]     (stateless)
Renderer R: UtterancePlan × VoiceProfile → text           (stateless)
```

- **Round-trip audit:** for every render, run `P(R(plan))` and require semantic fidelity
  ≥ θ against the plan (illocution match, content entailment, no *added* propositions).
  Failures are rejected and re-rendered; persistent failures are logged as renderer
  leakage — a measurable quantity, reported per build. "The LLM never smuggles
  cognition" stops being a slogan and becomes a regression test.
- **Voice profiles** are the only prose left in a character definition (Emma's rambling
  self-editing, Jake's flat economy). They may affect style only; content deltas are
  leakage by definition.
- Both functions are provider-agnostic and **record/replay cached** (C4): a run's
  language I/O is stored with the run; replays never re-call the API. Cached corpora also
  mean a classroom can run the engine offline.
- Long-term: the parser/renderer can be swapped for small local models or grammar-based
  realizers. The architecture must not care.

**Why it matters scientifically.** Every "LLM agent" paper since Generative Agents has an
unfalsifiable core. This contract is what lets us claim our agents' behavior is *caused*
by stated mechanisms — the language layer is measured, bounded, and replaceable.

### 4.14 · The personality layer (cross-cutting)

There is no "personality module." Personality is the **parameter vector** of all other
modules — which is the actual scientific claim of trait psychology (traits are summaries
of processing dispositions):

| Trait (Big Five) | Lands in |
|---|---|
| Neuroticism | M2 threat gain Γ, M3 negative decay Λ⁻, M9 loss sensitivity λ |
| Extraversion | M3 baseline v₀, M9 stimulation δ, M12 initiation thresholds |
| Agreeableness | M2 other-blame prior, M10 ε (sentiment repair rate), politeness W offsets |
| Conscientiousness | M9 goal persistence, M4 budget, M11 internalization ι |
| Openness | M1 novelty gating, M5 schema update rate, stimulation weight |

Plus the non-Big-Five dispositions: attachment style (M9 routing), regulatory style
(M4 policy priors), epistemic style (M6 gates), simulation budget (M7). A character is
~40 numbers, an initial belief/relationship state, and a voice profile. **Appendix A
instantiates all three v3.1 characters this way.**

## 5. Execution model

**Two timescales + one boundary.**

1. **Event loop (fast):** interactions are event-driven; a perceived event runs the
   pipeline M1→M2→M3/M4→M5(encode)→M6→M7→M8→M9→(M12→M13 if speaking). Latency budget:
   everything except M13 is pure computation — microseconds.
2. **Homeostatic tick (slow, per sim-minute):** decay laws — affect relaxation, need
   drain, activation decay, sentiment drift, load recovery.
3. **Consolidation boundary (per sim-day):** M5 consolidation, M8 narrative update,
   parameter-slow drifts. (The prototype's end-of-day card was accidentally profound.)

**Purity and replay.** The engine is a pure function
`step(WorldState, ExternalInputs, Seed) → (WorldState, Emissions)`. WorldState is fully
serializable; a run is (initial state, input log, seed, language-I/O cache) — replayable
byte-for-byte, forkable at any tick for counterfactuals (§6). The interactive game, the
headless batch runner, and the classroom client are all just *drivers* of `step`.

## 6. The instrument layer

This is what makes it a research platform rather than a demo.

**Provenance graph.** Every state delta records `(module, ruleId, inputs, output)`.
Query: "why did Emma approach the player at 5:12?" → the chain: exclusion event →
construal (private exchange witnessed) → relatedness drain → attachment activation 0.71 >
threshold → hyperactivation routing → proximity goal → approach. The v3.1 lens showed two
numbers; this lens shows the *causal graph of a mind*, and it is the educational product:
students click an utterance and walk backward through a cognitive theory.

**Intervention API.** Clamp or set any variable mid-run (`clamp(emma.M3.v, 0.8)`), lesion
any module (ablation), hot-swap theory cartridges (C3), fork state and replay recorded
inputs against modified parameters (**counterfactual replay**: "same day, Emma's
neuroticism at 0.2 — what changes?"). This is the difference between a terrarium and a
laboratory: the experiment is *the* first-class user story.

**Metrics library.** Deflection time series; CG-divergence matrices; belief-network
distance between agents; rumor mutation distance (edit distance in proposition space);
memory fidelity curves (trace vs. recall); need trajectories; relationship EPA phase
plots. Exports to tidy dataframes; notebooks as first-class artifacts.

**Batch harness.** Seeded Monte Carlo over parameter sweeps; scenario files declare
populations, layouts, schedules, event scripts; results land in a run store with full
provenance. A sociology instructor writes a scenario YAML, not JavaScript.

## 7. Emergent signatures (the engine's falsifiable bets)

If the architecture is right, these appear *without dedicated code*, and each one is a
demo, a teaching unit, and a paper section:

1. **Testimony drift** (M5): an agent's account of a past event shifts to match its
   current attitude toward the people involved.
2. **Serial gossip mutation** (M5+M12): multi-hop rumors deform toward each teller's
   schemas — Bartlett's serial reproduction, in silico.
3. **Sleeper effect** (M6): messages from distrusted sources gain force as source tags
   decay.
4. **Pluralistic ignorance** (M11): stable public enforcement of privately rejected
   norms, collapsible by one public dissent.
5. **Self-verification partner choice** (M8): agents with negative self-views seek
   confirming (unflattering) company — the strangest and therefore most valuable bet.
6. **Deflection-driven suspicion** (M10+M1): out-of-character kindness reads as creepy.
7. **Suppression leakage & duplicity detection** (M4+M7): performers get caught by good
   observers under load.
8. **Hostile attribution spirals** (M1+M3): conflict begets construal that begets
   conflict — with measurable escalation curves and identifiable defusion points.
9. **Reactance** (M9): pressure produces refusal against interest, scaled by construed
   (not actual) pressure.
10. **Public commitment hardening** (M8): audience multiplies dissonance and rationalization;
    private trusted challenge opens cracks. (Maya's arc — now a law, not a script.)

Each maps to a human experimental literature → each is a validation target with an
existing empirical benchmark. That's the research program in one list.

## 8. Prior art, and what is actually new

Honesty first — almost every *component* has an ancestor:

| System | What it did | Where we depart |
|---|---|---|
| **Generative Agents** (Park et al. 2023) | LLM-as-brain, memory stream, reflection via prompting; landmark believability | Inverted: explicit state, LLM at audited boundary; falsifiable mechanisms; deterministic replay |
| **PsychSim** (Pynadath & Marsella 2005) | Decision-theoretic recursive ToM | We ground inference in ACT's empirical equations; add affect, memory, identity, language |
| **EMA / FAtiMA** (Gratch, Marsella; Dias, Paiva) | Computational appraisal, used in FearNot! | Appraisal is one module of thirteen, closed-loop with memory/identity/norms |
| **BayesAct** (Hoey, Schröder) | ACT + POMDPs, mathematically deep | We operationalize ACT inside a full cognitive stack with language boundary |
| **Comme il Faut / Prom Week** (McCoy et al.) | ~5k authored social rules; brilliant, unmaintainable | Replace rule piles with a small set of dynamical systems + empirical dictionaries |
| **Versu** (Evans & Short) | Deontic social practices | Practices emerge from psychology instead of being authored |
| **Talk of the Town** (Ryan) | Knowledge propagation, fallible memory in a generated town | Deeper mechanism per belief (sources, reconstruction); interactive; instrumented |
| **The Sims** | Needs-driven behavior at scale | Psychosocial needs, prospect valuation, everything above the reservoir layer |
| **ACT-R / Soar** | General cognitive architectures, memory math | Social cognition is the object, not an application; multi-agent by construction |

**The six claims we can defend as new:**

1. **The cognition–language firewall with round-trip audit** — LLM as measured channel
   with a leakage metric, not as mind. No published agent system has this contract.
2. **ACT as runtime social physics fused with appraisal + identity control** — affect,
   action selection, and self-maintenance sharing one empirical currency (EPA).
3. **Reconstructive memory in interactive agents** — recall as schema-conditioned
   reconstruction, yielding testimony drift and serial rumor mutation as *mechanical*
   consequences.
4. **Misunderstanding as a measured quantity** — dual common-ground ledgers whose
   divergence is a number you can plot, teach, and experimentally manipulate.
5. **Theory cartridges** — competing theories of one construct behind one interface,
   with behavioral-signature comparison as a supported experiment type. The engine is an
   instrument for adjudicating theories, which is a methodological contribution
   independent of any single module.
6. **Full causal provenance of social behavior** — every utterance explodes into its
   generating chain. "Glass-box social cognition" as a product property.

## 9. Engineering plan

**Language & runtime.** TypeScript. One codebase runs in browser (interactive clients)
and Node (headless batch). Strict purity in core; effects only at drivers.

```
cogsim/
  packages/
    core/            # the engine — no LLM, no UI, no I/O
      src/substrate/ # events, propositions, EPA, blackboard, scheduler, provenance
      src/modules/   # m01-perception … m12-conversation (each: state schema,
                     #   update fn, params schema, observables, cartridge registry)
    lang/            # M13: parser/renderer contracts, providers, replay cache,
                     #   round-trip auditor
    lab/             # batch runner, intervention API, metrics, exporters
    clients/
      common-room/   # the game — a *driver* of core, and only that
      inspector/     # the cognitive debugger (lens 2.0)
  scenarios/         # YAML: populations, parameter kits, layouts, event scripts
  dictionaries/      # EPA dictionaries, appraisal prototypes, act lexicon
  docs/
    rfcs/            # one RFC per module — each written to stand alone (per-module
                     #   papers grow from these)
```

**Module contract.** Every module exports: `StateSchema`, `ParamsSchema`,
`update(state, inputs, params, rng) → (state', emissions, provenance)`, `observables`,
and registers under a construct interface for cartridge swapping (C3).

**Testing strategy.**
- Property tests on dynamics (boundedness, decay-to-baseline, conservation where claimed).
- **Phenomenon tests**: each §7 signature is an automated scenario with quantitative
  pass criteria.
- **The Common Room Protocol** (Appendix B): v3.1's authored behaviors as emergence
  acceptance tests.
- Renderer leakage tracked as a CI metric.

**Data.** EPA dictionaries are published research data (Indiana, Georgia, cross-cultural
sets) — sourcing/licensing them is an early task; until then, a hand-seeded mini
dictionary (~200 concepts) suffices for the reference scenario.

## 11. Risks, and ethics

**Technical risks, named honestly:**
- **Garbage at the boundary.** A bad parse poisons downstream cognition. Mitigations:
  parse distributions (not point estimates), plausibility gating in M6, repair moves in
  M12 — and the failure mode is at least *visible* in provenance, unlike prompt systems.
- **Tuning hell.** Thirteen coupled dynamical systems can oscillate or go flat.
  Mitigations: per-module property tests, staged integration (roadmap), empirical anchors
  (ACT coefficients, ACT-R decay constants) instead of free parameters wherever possible.
- **The seduction of the shortcut.** Every deadline will whisper "just let the LLM decide
  this one." C1 is a constitution, not a preference; the leakage metric is its court.
- **Wrong-abstraction risk.** Some construct boundaries (e.g., where construal ends and
  appraisal begins) may prove wrong. The cartridge system is the hedge: boundaries are
  interfaces, and interfaces can be re-drawn per major version without erasing the
  science done on either side.

**Ethics.**
- Parameter kits model *theories*, not people or demographics. Documentation must state
  constructs and their evidential status; shipping a "person type" library would be both
  scientifically wrong and socially harmful.
- Training applications (therapy practice, autism social-skills rehearsal, negotiation)
  require validation studies before any efficacy claim; the engine's explainability is an
  asset for IRB review, not a substitute for it.
- Simulated social data must never be passed off as human data; exports are watermarked
  as synthetic.

## Appendix B — The Common Room Protocol (v3.1 as test oracle)

Scripted behaviors in the prototype become emergence tests. Pass = behavior occurs from
general mechanisms with the character's parameter kit; fail = it needed special-casing.

| Test | Setup | Pass criterion |
|---|---|---|
| **EMMA-1** | Player converses privately with Jake twice; ignores Emma 20+ min | Emma initiates approach; provenance chain shows relatedness drain → attachment activation > θ, no scripted trigger |
| **EMMA-2** | Warm consistent attention across a day | Activation baseline drops; approach frequency normalizes (security update) |
| **JAKE-1** | Player flatters Jake 3× | Jake's reliability estimate of player *falls*; sentiment E unchanged or ↓ |
| **JAKE-2** | Player argues well against Jake's position | Belief credence moves; sentiment P toward player ↑ (argument quality decoupled from liking) |
| **MAYA-1** | Violin challenged with audience present | Dissonance ↑, rationalization act (consonant-info assertion), commitment unchanged |
| **MAYA-2** | Same challenge, backstage, sentiment E > θ | p_leak crack: display drops, hedged concession parse in output frame |
| **GOSSIP-1** | Player tells Emma juicy claim about Jake | Claim reaches Maya ≤ 1 sim-day, content mutated toward Emma's schemas (edit distance > 0) |
| **MEM-1** | Neutral shared event day 1; relationship soured day 2 | Day-3 recall of event reconstructs negative-shifted attributes; trace log unchanged |
| **NORM-1** | Repeated unsanctioned violation of a seeded norm | All agents' D̂ shifts; norm compliance decays population-wide |
| **FIREWALL-1** | 1,000 rendered utterances | Round-trip fidelity ≥ θ on ≥ 98%; zero added-proposition leaks in accepted outputs |

The prototype's three characters are the engine's first benchmark. When the Common Room
Protocol is green, we will have replaced three personality essays with one theory of
minds — and that is the moment this stops being a demo and becomes an instrument.
